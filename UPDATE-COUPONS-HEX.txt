PRODUCT COLOURS
 - Each colour row: Colour name + HEX code (e.g. #000080) + stock. The swatch shows the colour as you type.
 - Accepted: #000080, 000080, #FFF (saved as #FFFFFF). Invalid codes are shown in red and cannot be saved.

COUPONS (Admin > Coupons & Discounts)
 - Create / edit / delete, switch Active on or off from the list, search and filter by status.
 - Each coupon: code, percentage (fixed PKR amount also available), applies to, start date, expiry date,
   usage limit (optional), minimum order amount (optional), Active / Inactive.
 - Status in the list: Live, Scheduled, Expired, Used up, Inactive.
 - Discounts are always calculated and checked on the server. One coupon per order.
 - Usage limit counts all customers together. Cancelling an order gives its coupon use back.
 - Specific products / categories: only those items are discounted; the minimum order uses the whole cart subtotal.
